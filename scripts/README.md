## Contexto

Inicialmente, foi obtido dados de um estacionamento de uma instituição religiosa, como entrada e saída de carros, números de mensalistas. Com essas informações é possível juntar os dados em um arquivo como o CSV que vai ser utilizado, depois do tratamento de dados (respeitando o ETL - Extract, Transform and Load), é feito um novo arquivo CSV com esses dados tratados e finalmente é criado o dashboard para a melhor visualização desses dados e com isso, é possível ter uma melhor tomada de decisões.
